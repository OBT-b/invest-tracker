信貸投資記帳

資料存放在你的 GitHub 私人 repo。這個網頁本身不含任何資料，需要你的存取權杖才能讀寫。

如何建立存取權杖？
  1. 到 GitHub → 右上角頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Expiration 選一個期限（到期後回來重新產生即可）。
  3. Repository access 選 Only select repositories，只勾選資料 repo（invest-data）。
  4. Permissions → Repository permissions：Contents: Read and write、Actions: Read and write。
  5. 產生後複製貼到上方。權杖只會存在這台裝置的瀏覽器裡，按「登出」即可清除。

新增定存

利息按實際天數 ÷ 365 計算。整存整付每月複利；存本取息每月計息、本金不變。
利息會算在「定存現值」裡。實際領到利息時，到「交易紀錄」記一筆股息（或用下方的「記錄領息」），現金才會增加，總資產不會重複計算。
單筆利息滿 2 萬會被扣 10% 稅與 2.11% 補充保費，需要時在「預扣稅率」填 12.11。
